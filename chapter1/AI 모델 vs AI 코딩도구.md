## AI 모델
언어를 이해하고 답변을 생성하는 AI  
쉽게말해서 '두뇌'  
수십억 개 텍스트 데이터 학습 -> 언어 패턴과 맥락 이해  

한계: 대화만 가능, 실제 작업은 불가  

#### 모델 종류
어떤 데이터 어디에 중점 -> 다른 답변 스타일
* Claude - Anthropic: 코딩 정확도 높음, 신중한 답변
  * 원칙 기반 훈련: AI에게 원칙을 가르쳐서 스스로 판단
* GPT - OpenAI -> 범용적, 유연한 답변에 강함
  * 피드백 기반 훈련: 사람들 선호 답변을 대량 학습
* Gemini - Google -> 멀티미디어 이해에 특화
  * 멀티모달 설계: 텍스트 이미지 영상 동시 이해  

## AI 코딩 도구
AI 모델에 실제 행동 능력을 부여  
'손과 발'  

#### 종류
* 터미널 기반 - 자율적 작업
  * 목표만 말하면 프로젝트 전체 분석 -> 자율 작업
  * Claude Code, Gemini CLI
* 데스크톱 IDE - 코드 편집기 내 지원
* 웹 IDE - 설치 없이 브라우저에서
  * 복잡한 프로젝트에는 한계

#### 나한테 맞는 도구는?
* 빠른시작, 진입장벽이 쉬운것: 웹
* 코드 직접 수정, 일상 개발: 데스크톱 IDE
* 프로젝트 전체, 가장 강력: 터미널
    
#### 중요포인트
같은 Claude 모델, 다른 경험  
여러 도구에서 같은 모델 사용 -> 모델은 같지만 경험은 완전히 다름.  
왜?  
각 도구가 AI를 활용하는 방식이 다름
* 시스템 프롬프트(기본 지시가 다름)
* 에이전트 루프(일하는 방식이 다름)
* 컨텍스트 관리(기억하는 방식이 다름)
* 전용기능(Skills, Memory 등)

AI모델 = 엔진, AI도구 = 차종  
같은 엔진이더라도 차종에 따라 용도가 다르다!  

#### 트랜드
코드 편집기 기반 vs 터미널 기반  
코드 편집기 기반: 열린 파일 중심 -> 빠른 응답  
막히는 곳에서만 도움을 받음  

터미널 기반: 프로젝트 전체 분석 -> 자율 작업 

AI모델 성능은 비약적 향상, 직접 타이핑 필요가 줄어듬.  
터미널 기반으로 강력하게 사용하자!!  
코딩역할: 타이핑 -> 의사결정
